# Frozen companion package

This course uses AEC 0.2.0. Its exact source archive is included
here and verified against the SHA-256 in manifest.tsv before installation.
Run `Rscript --vanilla scripts/setup.R` from the book root to restore CRAN
dependencies and install this archive into `.course-library/`. No moving
GitHub HEAD, sibling source checkout or global package replacement is needed.
The archive retains the package's own software and data licence notices.
