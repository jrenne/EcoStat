## Statement
Are the following statements True or False? (Provide short explanations.)\
We consider a null hypothesis $H_0$. Under that null hypothesis, the test statistic $z$ is $\mathcal{N}(0, 1)$. We use a two-tail rejection region (a *two-sided test* in the terminology of this course) and set its size $\alpha$ at 5%.

1.  Using our data we get $z = -3.2$. We reject the null hypothesis.

2.  Under $H_0$, the probability of making type-I errors is 5%.

3.  The probability of making Type-II error is smaller than 5%.

4.  The size (or level) of the test is the probability to make Type-II errors.

5.  If I am very averse to Type-I error, I choose a low value for the size of the level.
