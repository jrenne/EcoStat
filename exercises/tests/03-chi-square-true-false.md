## Statement
We consider a test whose test statistic is denoted $z$. Under the null hypothesis ($H_0$), $z$ follows a $\chi^2(7)$ distribution (chi-squared with 7 degrees of freedom; see table below). The rejection region is in the upper tail (a *one-sided test* in the terminology of this course).

For each statement, decide whether it is true or false and justify your answer.

1. If $z \ge 10$, we always reject the null hypothesis at the 5% significance level (test size $\alpha=5\%$).

2. If $H_0$ is valid, and when the test size ($\alpha$) is 10%, the probability of making a Type I error is 10%.

3. The power of the test is necessarily greater than the size of the test.

4. Under $H_0$, the probability of having $-1.96<z<1.96$ is approximately 95%.

5. If the p-value of the test is 1.5%, we reject $H_0$ at the 5% significance level (test size $\alpha=5\%$).
